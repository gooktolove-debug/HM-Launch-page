MOORING INTEGRATION

1. Copy the mooring folder to the repository root.
2. Copy apply-mooring-integration.py to the repository root beside index.html.
3. From the repository root run:
   python apply-mooring-integration.py
4. Confirm these changes:
   - mooring/index.html added
   - root index.html modified
   - a small grey buoy icon appears at the bottom centre of the Windy panel
5. Commit and push.

The script creates index.before-mooring.html as a backup. Delete the backup and script before pushing if you do not want them in GitHub.
